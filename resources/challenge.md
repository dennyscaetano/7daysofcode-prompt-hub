Your challenge is to build a backend application using Node.js, TypeScript, and the Express library, which is widely used in building web servers. You will also be challenged to build automated tests for your application using the Jest and Supertest libraries, as well as learn how to build a workflow in Github Actions to automate the execution of your tests.

All examples in this challenge will be based on these technologies. However, nothing prevents you from selecting or using other tools. Feel free to go further!

An important piece of information to mention is that this project used Node version 18 (v18.12.1) to build this challenge!

During the development of this challenge, you will:

- Não Build an API using Node.js, TypeScript, and Express;
- Não Integrate with the Google Gemini AI model API;
- Write unit and integration tests using the Jest library;
- Learn what GitHub Actions are;
- Set up an automated test execution workflow using GitHub Actions;
